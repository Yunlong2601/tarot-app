## Concrete friction removed

- Searching a long card list: a position-level name/keyword/English-alias filter now narrows the native select. Selected cards stay visible even when not matched; the count reports actual matches. Empty filters can be cleared without changing cards. Localised card names and English names both work.
- No clear next activity: existing practice progress now points directly to the first untried activity. All tried leads to reviewing a reflection, with no accuracy score or certificate claim.
- Accidental overwrite: Save and Restore now use an accessible in-page confirmation when a different existing version would be replaced. Cancel/Escape preserves both versions; export remains the way to keep multiple copies. App Premium history/journal is unchanged.
- Unstructured corrections: methodology now asks for URL/language/passage/rationale/source and links to the existing Support email. No fake reviewer or automatic submission is implied.
